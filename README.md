# 序闻 AI / SIGNAL

高级黑白风格的 AI 资讯精选网页。来自腾讯、百度与阿里巴巴官方渠道，按时间、背景、内容和来源整理，附逐条核验说明。

- 本期共 7 条：腾讯 3 条、百度 2 条、阿里巴巴 2 条。
- 核验日期：2026-09-27；原文发布日期：2026-08-28 至 2026-09-22。
- 支持平台筛选、关键词搜索、时间排序、核验详情、JSON 导出及打印。
- 本站是静态精选版，不会自动采集或更新。

## 文件

- `index.html`：独立网页，内嵌样式、脚本与数据。
- `news-data.json`：结构化资讯和官方来源。
- `verification-report.json`：来源日期、标题校验与内容哈希。
- `.nojekyll`：直接发布静态文件。

## GitHub Pages

发布源为 main 分支根目录，项目站点地址为 https://chen111-tag.github.io/CODEX_TEST1/ 。

## 核验边界

核验范围为官方来源身份、发布日期及摘要与原文的一致性。企业性能、应用效果与监管相关陈述按来源口径标注，不视为独立测评结论。
